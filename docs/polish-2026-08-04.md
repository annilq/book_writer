## Defects found & fixed

### P0/HIGH — Completion ceremony had no escape
`app/content/[id]/page.client.tsx` — the book-complete celebration overlay could only be dismissed by navigating away (which unmounted the component). Added a backdrop-click-to-close and a top-right close (X) button with `aria-label={t("close")}`, so the success state is completable without forced navigation.

### P1/MEDIUM — Reconnecting banner used raw color (drift)
`app/books/[id]/agent/AgentProgress.tsx` — the transient reconnecting state used hardcoded `amber-500` instead of the design system's `warning` semantic token. Switched to `border-warning/30 bg-warning/10 text-warning` for cross-theme consistency.

### P2/LOW — Redundant disabled+spinner on send button
`components/Chat/chat-box.tsx` — during streaming the send button showed a spinner while disabled, duplicating the dedicated stop button's job. Now shows the arrow always (stays disabled during streaming); removed the now-unused `Spinner` import.

### P3/LOW — Leftover debug output
`app/books/[id]/components/outline-sheet.tsx` — removed `console.log(nodeEl)`.
